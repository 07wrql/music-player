# VS1003B 蓝牙音箱母板原理图初版

本稿根据当前 STM32 工程的实际配置和你提供的 F407 插针板照片整理，目标是：F407 开发板、VS1003B 模块、MicroSD 卡和蓝牙模块均采用插接方式，母板提供 5 个独立按键、调试接口、电源和音频扩展接口。不使用蜂鸣器。

## 1. 当前工程已经确定的连接

| 功能 | 母板网络名 | STM32F407 引脚 | 模块端 |
|---|---|---|---|
| VS1003 SPI 时钟 | VS_SCK | PA5 / SPI1_SCK | SCLK |
| VS1003 SPI 主入 | VS_MISO | PA6 / SPI1_MISO | MISO |
| VS1003 SPI 主出 | VS_MOSI | PA7 / SPI1_MOSI | MOSI/SDI |
| VS1003 命令片选 | VS_XCS | PA4 | XCS |
| VS1003 数据片选 | VS_XDCS | PA3 | XDCS |
| VS1003 数据请求 | VS_DREQ | PB0 | DREQ |
| VS1003 复位 | VS_XRST | PB1 | XRST/XRESET |
| SD 卡时钟 | SD_SCK | PB10 / SPI2_SCK | CLK |
| SD 卡主入 | SD_MISO | PB14 / SPI2_MISO | DO/MISO |
| SD 卡主出 | SD_MOSI | PC3 / SPI2_MOSI | DI/MOSI |
| SD 卡片选 | SD_CS | PC1 | CS |
| 现有按键 | KEY_NEXT | PC13 | KEY_NEXT |

> 注意：工程说明文档中曾把 SD MISO 写成 PC2，但 `spi.c` 和 `vs1003b.ioc` 的实际配置是 PB14，原理图按 PB14 设计。

## 2. 母板功能框图

```text
                         +----------------------+
  5V_IN / 电池 ----------| 电源与保护            |
                         | 5V -> 3V3（可选）     |
                         +----------+-----------+
                                    |
          +-------------------------+--------------------------+
          |                         |                          |
   +------v------+           +------v------+             +-------v-------+
   | F407 插座   |           | VS1003B 插座|             | 蓝牙模块插座   |
   | 主控模块    | SPI1 ---->| SPI/控制     |             | VCC/GND/信号  |
   | SWD/3V3/GND |           | L/R 音频输出  |             | 预留电源开关   |
   +------+------+           +------+-------+             +---------------+
          |                         |
          | SPI2                    +----> 音频功放/耳机接口
   +------v------+                  |
   | MicroSD 插座|                  +----> VS_LINEOUT_L/R 测试点
   +-------------+

   PD0~PD3 + PC13 ---- 五个按键（按下接地，输入上拉）
```

## 3. 五个按键

当前工程只配置了 PC13，因此建议母板先按下面的网络名预留；按键功能和 GPIO 号需要同步补进 CubeMX/代码：

| 按键 | 网络名 | 推荐主控引脚 | 接法 |
|---|---|---|---|
| KEY1 | KEY_NEXT | PC13 | GPIO 输入上拉，按下接 GND |
| KEY2 | KEY_PREV | PD0 | GPIO 输入上拉，按下接 GND |
| KEY3 | KEY_PLAY | PD1 | GPIO 输入上拉，按下接 GND |
| KEY4 | KEY_VOL_UP | PD2 | GPIO 输入上拉，按下接 GND |
| KEY5 | KEY_VOL_DOWN | PD3 | GPIO 输入上拉，按下接 GND |

每个按键建议并联 100 nF 到 GND 做硬件去抖，串联 1 kΩ 可作为可选保护电阻；若使用 STM32 内部上拉，外部上拉电阻默认不装但 PCB 预留焊盘。

你提供的 F407 板顶边和底边均引出了 D0、D1、D2、D3，因此 PD0~PD3 可直接从主控插座引出；PC13 也已在板上引出。原理图中的五个按键按“按下接地、GPIO 上拉、低电平有效”设计。

## 4. VS1003B 插座

建议使用 2.54 mm 双排排针或与实际模块匹配的母座，至少引出：

```text
VS1003_VCC  -> 3V3
VS1003_GND  -> GND
VS_SCK      -> PA5
VS_MISO     -> PA6
VS_MOSI     -> PA7
VS_XCS      -> PA4
VS_XDCS     -> PA3
VS_DREQ     -> PB0
VS_XRST     -> PB1
LINEOUTL/R  -> 音频接口/功放接口（按模块实际引脚命名）
```

VS1003B 电源入口旁放置 100 nF + 10 µF 去耦；SPI 线尽量短，XCS、XDCS、XRST 和 DREQ 不要与功放输出线平行长距离布线。

## 5. MicroSD 插座

使用 3.3 V MicroSD 卡座，按 SPI 模式连接：

```text
SD_VDD -> 3V3
SD_GND -> GND
SD_CLK -> PB10
SD_DO  -> PB14
SD_DI  -> PC3
SD_CS  -> PC1
```

SD_CLK、SD_DI、SD_DO、SD_CS 建议各预留 22~47 Ω 串联电阻位置，SD 信号附近放置 100 nF 去耦。SD 卡座的 CD 检测脚可引出为 `SD_CD`，不接入当前固件。

## 6. 蓝牙模块接口

由于尚未给出蓝牙模块型号，先使用通用 1×6 插座：

```text
BT_VCC、BT_GND、BT_TX、BT_RX、BT_EN、BT_STATE
```

BT_VCC 不要直接假定为 3.3 V：若模块是 5 V 供电，接 `VBUS_5V`；若是 HC-05、JDY 等 3.3 V 逻辑模块，接 `3V3`。BT_TX/BT_RX 必须根据模块电平确认，必要时给 BT_RX 加分压或电平转换。

## 7. 电源和调试接口

- 输入：`POWER_IN` 两针，建议标注极性；增加保险丝/反接保护和电源指示灯。
- 电源网络：`VBUS_5V`、`3V3`、`GND` 分开命名；VS1003B、SD 卡和 F407 的逻辑电源必须共用 3.3 V 地。
- F407 插座至少引出 `3V3`、`GND`、`NRST`、`SWDIO`、`SWCLK`；推荐另外引出全部未使用 GPIO 排针，便于后续扩展。
- 在 `3V3` 和 `VBUS_5V` 各放一个测试点，在 VS1003B 的 `DREQ`、`VS_XCS`、`VS_XDCS` 旁放测试点。

## 8. 当前已确认的 F407 主控板

从照片可以确认该板采用 2.54 mm 间距、两侧多排 GPIO 焊盘/插针，丝印直接标出 STM32 GPIO 名称，母板可按丝印网络名连接，不需要依赖开发板的物理排针编号。正式绘图时应以实物两侧焊盘的列数和孔位尺寸建立母座封装，不能直接套用通用 2×25 排针封装。

主控相关连接仍以工程代码为准：`PA5/PA6/PA7` 接 VS1003B，`PB10/PB14/PC3` 接 SD 卡，`PC1` 接 SD_CS，`PC13/PD0/PD1/PD2/PD3` 接五个按键。

## 9. 录入嘉立创 EDA 前必须确认

1. VS1003B 模块的准确型号、接口排布和是否已经带晶振、稳压、耳机放大/滤波电路。
2. 蓝牙模块型号及供电电压、串口是否需要电平转换。
3. 音频输出最终接耳机、功放模块，还是板上集成功放。
4. 母板输入电源是 USB 5 V、锂电池还是其他电压。

在这五项确认前，不建议直接下单 PCB；尤其是 F407 和 VS1003B 的插座封装，外形相近但排针定义经常不同。
